# TSW6-Pure-EBuLa

Standalone Pure EBuLa monitor for Train Sim World 6.

Phase 1 intentionally contains only the EBuLa monitor: timetable display, navigation, clock controls, FSD, track change, day/night, display mode and fullscreen.

No Tacho, LZB, PZB, MFA or locomotive dashboard is included.

The TSW6 bridge is deliberately deferred until the standalone monitor is tested and stable.

The first dataset is an original small demonstration timetable for UI testing.
